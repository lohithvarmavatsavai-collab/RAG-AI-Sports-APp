Model Card · AI Sports Performance Assistant

Model Details

  • Developer: ISE 244 Graduate Student, SJSU · April 2026 · v1.0
  • Type: Retrieval-Augmented Generation (RAG) pipeline
  • Retrieval: FAISS flat L2 index + SentenceTransformers all-MiniLM-L6-v2
  • Generation: Google Gemini 2.5 Flash · temp 0.25 · max 1,500 tokens
  • Retrieval params: top_k = 6 · chunk ≤ 350 chars · structured 6-section output
  • License: Academic / Non-Commercial · Contact: SJSU Canvas submission

Intended Use

  • Evidence-based sports guidance (training, nutrition, recovery) for recreational/amateur athletes
  • ISE 244 RAG demonstration — grounding LLM outputs in authoritative sports science sources
  • RAG vs. ungrounded baseline comparison for graduate-level evaluation

Out-of-scope: medical diagnosis, professional-elite programming, sports beyond the four covered, users under 16.

Factors

  • Experience level — recommendations personalized per Beginner / Intermediate / Advanced
  • Sport — filter applied at retrieval; cross-sport contamination is an edge-case risk
  • Query specificity — vague queries retrieve lower-quality chunks
  • Category alignment — Training / Nutrition / Recovery filter boosts precision
  • API availability — Gemini requires internet; FAISS retrieval is fully local

Evaluation factors: Sport × Category × Experience Level (intersectional subgroups shown at right)

Metrics

  • Precision@6 — fraction of 6 retrieved chunks judged relevant by human evaluator
  • L2 Distance — FAISS similarity score per chunk (lower = more relevant)
  • Section Completeness — all 6 output sections present and non-truncated
  • Numerical Traceability — specific numbers traceable to a retrieved chunk
  • RAG vs. Baseline Delta — specificity gain over ungrounded LLM baseline

Thresholds: well-retrieved ≥ 4/6 chunks; accurate if ≥ 80% numerical claims source-traceable.

Training Data

  • 36 curated documents · 123 indexed chunks · 4 sports × 3 categories
  • Soccer: FIFA, UEFA, F-MARC, ISSN, ACSM, GSSI
  • Tennis: ITF, USTA, ATP/WTA, USOPC, BJSM, ITF Medical Commission
  • Basketball: FIBA, NBA Performance Lab, NCAA, NBPA, ACSM, GSSI
  • Strength: NSCA, ACSM, ISSN, NIH, USDA, JSCR (sources 2021–2023)
  • No model weights trained — knowledge is entirely retrieval-based

Evaluation Data

  • 10-question hand-crafted set covering all 4 sports, 3 categories, 3 experience levels
  • Each question run twice: RAG pipeline and ungrounded Gemini baseline
  • No preprocessing — natural language queries as typed by real users

Ethical Considerations

  • System prompt hard-codes: "Never diagnose injuries, prescribe supplements, or give medical advice"
  • Every answer includes a mandatory ⚠️ Limitations section + UI-level legal disclaimer
  • Source material primarily from elite male athlete data — female athletes, youth (<18), older adults (55+), and para-athletes may need professional adaptation
  • API key stored in .env, excluded from version control

Caveats and Recommendations

  • Not a clinical tool — outputs are general educational content only
  • Static knowledge base (2021–2023); verify against current governing body publications
  • Precision@6 drops to 67% on abstract or advanced-level queries
  • No real-time biometrics — personalization based on self-reported inputs only
  • Future work: Hybrid BM25 + FAISS; cross-encoder re-ranking; female athlete guidelines; ROUGE-L / BERTScore evaluation
